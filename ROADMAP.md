# Current work

## First stable release

Prepare coherent development source, ordinary release tooling, package lifecycle
regressions, and independent WsprryPi consumer support. Validate exact source,
UAPI, package, and runtime identities without inheriting another repository's
publication or qualification claims. The first stable release is `v1.0.0` and
requires an explicit user readiness decision.

## Provider maintenance

Maintain bounded UAPI behavior, stock-kernel resource ownership, route-neutral
packaging, single-route administration, cancellation, and attributable recovery.
Preserve deterministic host and disposable-container regression coverage.
Each target, kernel, route, waveform, and RF qualification claim requires its
own scoped evidence. WsprryPi owns production selection and product acceptance.
